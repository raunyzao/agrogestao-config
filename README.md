# AgroGestão - Projeto de exemplo para gerenciamento de configuração

Projeto didático em Python que representa funções simples para um aplicativo de apoio a propriedades rurais.

## Arquivos
- `novo.py`: resumo dos dados de uma propriedade, atualizado durante a atividade.
- `nova_funcionalidade.py`: função nova para estimar a produção a partir da área e da produtividade.

## Execução
Use Python 3 para executar `novo.py`. A função de estimativa pode ser importada de `nova_funcionalidade.py`.

## Configuração inicial do Git

## Alterações do exemplo
O README descreve o projeto AgroGestão. O arquivo `novo.py` apresenta e valida dados de uma propriedade. O arquivo `nova_funcionalidade.py` estima a produção. Depois de clonar este repositório, edite este README para registrar a atividade e pratique `git status`, `git add`, `git commit` e `git push`.
